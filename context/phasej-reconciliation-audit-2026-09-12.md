## 2. 结论一：同一个 SKU，不是两个 identifier level

- `1007614764`（10 位）在全部源文件中**独立出现次数为 0**（raw / parsed / csv / summary，带数字边界正则核查）。
- `10076147649602`（14 位）是 JD API 字段 `ItmSkuId`（解析后 `sku_id`），隶属于 `ItmId=10023968977041`（解析后 `spu_id`，SPU 层）。
- `1007614764` 恰好是 `10076147649602` 的前 10 位前缀；商品名一致、件数 20 与 header 口径精确吻合。
- **判定**：同一 SKU。10 位形式是 Task 1 Audit 转录时的截断，不是源系统存在的另一级 identifier。源系统真实的两级是 **SPU(ItmId=10023968977041) → SKU(ItmSkuId=10076147649602)**。

## 3. 结论二：两个 GMV 来自两种合法聚合粒度（header / child）

源数据结构（JD 订单明细 API 的 `children[]` 设计）：

- **header 行（父订单行）**：`ord_amt` = **整单实付金额**，`sku_id` = 订单锚定/主 SKU，`sale_qty` = 整单件数（含连带 SKU 与 0 元赠品）。
- **child 行（SKU 明细行）**：`ord_amt` = 该 SKU 行实付金额，`sale_qty` = 该行件数。

09-01 该 SKU 出现在 4 个订单中：

| 订单 | header 金额（B 锚定） | B 的 child 行金额 | 差异构成 |
|---|---|---|---|
| 3608410004895473 | 650.35（qty 3） | 650.35（qty 1） | 0 元赠品 |
| 3608431016995709 | **2201.04**（qty 11） | **1782.85**（qty 3） | 连带 SKU 10072457536641（茉莉王妃）¥418.19（qty 1）+ 赠品 7 件 ¥0 |

| **合计** | **¥3932.08 / 20 件** | **¥3513.89 / 6 件** | **Δ = ¥418.19 / 14 件** |

差额 ¥418.19 与那一行连带 SKU 金额**精确相等**。

### 命名两种 metric（均为合法语义，今后必须带粒度引用）

| 名称 | 定义 | 09-01 B SKU |
|---|---|---|
| **订单锚定成交额（order-anchored GMV，header 口径）** | 以该 SKU 为主商品的父订单**整单金额**合计，含连带销售与赠品；回答"主推该 SKU 的订单带来多少成交额" | ¥3932.08 / 20 件 / 占日 GMV **37.1%** |
| **SKU 行级成交额（SKU-line GMV，child 口径）** | 仅汇总该 SKU **自身明细行**金额，不把连带 SKU 记到它名下；标准"单品 GMV/贡献"定义 | ¥3513.89 / 6 件 / 占日 GMV **33.1%**；占已拆分明细小计 ¥8169.08 的 43.0% |

## 4. Task 2 aggregation 是否错误：否（STOP 条件未触发）

- Task 2 `computeTopContributors` 以 **child 行 group by sku_id 求和**作分子 —— 这是标准单品 GMV 归因，不会把别人的 ¥418.19 记到 B 头上。
- 分母用当日真实 GMV ¥10609.95（= Σ header ord_amt，与 KPI 口径一致）。33.1% 回答"该 SKU 自身行占店铺当日 GMV 比例"，语义自洽；改用 ¥8169.08 作分母得到 43.0% 反而**高估**，因为：
- **源数据结构性缺口（H≠S 的来源，保留不平）**：09-01 37 个父订单中 18 个（¥2440.87 / 18 件）在 JD 负载里**没有 children 行**；有 children 的 19 个订单，child 金额合计与 header 金额**逐单精确相等**（child<hdr 订单数 = 0）。故 Σ child = ¥8169.08 < GMV ¥10609.95 是"部分订单无 SKU 拆分"造成的，不是行级金额算错。
- 对 SKU B 而言行级归集是**完备**的：B 不出现在任何 header-only 订单，也从不在非 B 锚定订单里作 child（8 条命中 = 4 header + 4 child，同 4 单），故 ¥3513.89 即 B 的真实单品 GMV，不存在被遗漏的 B 行。
